# VWorld 5단계 검증 결과

검증일: 2026-10-27

## 자동 테스트

- 전체 기존·신규 테스트: `python -m pytest tests -q` → 155 passed, 57 subtests passed.
- 이후 파일 입출력·최초 키 등록 흐름 테스트 3개 추가.
- 추가 후 VWorld UI 통합 테스트: `python -m pytest tests/test_vworld_integration.py -q` → 18 passed (추가 3개 포함).
- 전체 테스트에서 실패 없음. 엑셀 출력, GBIF, SQL, 미디어, 업로드, 서비스 분리 및 VWorld 테스트 포함.
- 실제 임시저장 JSON에 법정동코드·주소 메타데이터 보존 확인.
- 엑셀 출력에서 기존 컬럼 순서 유지, 시군구 결합값 보존, 내부 메타데이터 미노출 확인.
- 키 없는 최초 사용에서 설정창을 열고 등록 후 조회에 사용하는 흐름 확인.

## 실제 서비스·보안 저장

4단계에서 등록된 키로 서울·안양·부산 동래구·경주·남해 및 해양 좌표 조회를 완료했다.
주소 자료는 `tests/fixtures/vworld_live_addresses.json`에 있으며 키·요청 URL은 포함하지 않는다.
인증 실패·연결 오류·요청 제한은 합성 오류로 검증했으며 실제 키 설정을 훼손하거나 한도를 소진하지 않았다.

Windows 보안 저장은 임시 식별자로 저장·조회·삭제를 확인했다.
5단계에서는 동일 API 키 서비스를 PyInstaller 6.9.0으로 별도 검증용 EXE에 패키징하여
`FROZEN_VAULT_OK` 결과와 종료 코드 0을 확인했다. 실제 등록된 키는 이 검증에서 읽거나 변경하지 않았다.

## 검증 범위의 한계

- 전체 BioFlow 배포 EXE를 새로 빌드·배포하지 않았다. 패키징 검증은 보안 저장 서비스용 EXE다.
- 사용자 XML 원본 명세가 제공되지 않아 XML/JSON 필드 대조는 수행하지 않았다.
- 실제 VWorld 키 만료·허용 도메인/IP 실패·요청 한도 초과를 고의로 발생시키지 않았다.
- 전국 주소 전수 검증이나 영문주소 SQLite 구축은 범위 밖이다.

사용법과 실제 응답의 특이점은 `vworld-stage4.md`를 참고한다.
