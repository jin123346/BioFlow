# VWorld 주소 조회: 3단계

이 문서는 3단계 완료 당시의 기록이다. 현재 UI 연동은 [4단계 안내](vworld-stage4.md), 최종 검증은 [검증 결과](vworld-validation.md)를 참고한다.

## 사용 방법

1. 의존성을 설치하고 BioFlow를 실행한다: `python -m pip install -r requirements.txt`
2. 상단 **설정 → VWorld API 설정**을 연다.
3. API 키를 입력하고 **저장 / 변경**을 누른다. 발급 정보의 만료일은 선택 사항이다.
4. 위도·경도를 입력하고 **연결 테스트**를 누른다. 아직 저장하지 않은 입력 키로도 테스트할 수 있다.
5. 키는 Windows 사용자 보안 저장소에 저장되며, 다음 실행에서 자동으로 읽는다. **키 삭제**는 이 서비스의 저장 항목만 삭제한다.

서비스 식별자: `BioFlow.VWorld.Address`. 키와 선택적 만료일을 같은 보안 항목에 저장한다.
평문 파일 저장 대체 경로는 없다. 다른 OS용 보안 저장소는 현재 지원하지 않는다.
등록된 만료일이 지난 경우 안내하며 실제 인증 결과와 구분한다.

## 구현 범위

- API 요청: EPSG:4326, 경도·위도 순서, PARCEL, JSON, simple=false.
- 응답 구조 검증 및 법정동코드 문자열 보존. 숫자 코드 응답은 앞자리 복구가 불가능하므로 거부한다.
- 좌표 오류, 키 누락, 인증, 요청 제한, 결과 없음, 네트워크, 타임아웃, JSON/구조 오류 처리.
- 원본 서버 오류나 키가 포함된 URL을 사용자 메시지로 전달하지 않는다.
- 연결 테스트는 작업 스레드에서 실행한다. 실행 중 설정 변경 및 창 닫기를 제한하고 완료 후 해제한다.
- 기존 주소 조회 버튼, Nominatim, 엑셀 필드는 변경하지 않았다. 최초 주소 조회 시 설정창 연결, 국문 매핑, 미리보기, 일괄 처리 및 메타데이터 보존은 4단계 범위다.

## 검증과 남은 사항

`python -m pytest tests/test_vworld_services.py tests/test_upload_workflow.py -q`

서비스 테스트의 JSON은 사용자 명세를 바탕으로 만든 합성 응답이며 실제 VWorld 응답 수집본이 아니다.
실제 키 연결, XML 명세와 JSON 비교, 정확한 공급자 오류 코드 목록 확인 및 지역별 실제 주소 검증이 남아 있다.
실제 응답에 따라 인증 오류 코드 분류를 보완해야 할 수 있으며, 미분류 ERROR도 안전한 일반 오류로 처리한다.
Windows 보안 저장소는 별도 임시 식별자의 테스트 값으로 저장·조회·삭제를 확인했다.
배포 EXE에서의 keyring 동작은 배포 검증 단계에서 추가 확인해야 한다.
