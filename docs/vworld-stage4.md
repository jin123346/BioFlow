# VWorld 국문주소 UI 연동 (4단계)

## 사용법

- 관찰·표본의 **위도/경도로 주소 조회**는 현재 입력폼의 좌표를 조회한다.
- **위치 전체 주소 조회**는 유효한 좌표가 있는 모든 행을 조회한다. 기존 주소가 있는 행도 결과를 비교할 수 있다.
- 키가 없으면 API 설정창을 열고, 저장된 키가 있으면 자동 사용한다.
- 조회는 작업 스레드에서 실행한다. 조회·미리보기 창이 열려 있는 동안 편집창 입력은 잠근다.
- 결과 미리보기의 기본값은 **빈칸만 채우기**다. 덮어쓰기를 선택해도 응답의 빈 필드는 기존 값을 지우지 않는다.
- 미리보기에서 적용을 눌러야 데이터가 변경된다. 실패·중단한 행은 그대로 유지한다.
- 조회 중 취소하면 현재 요청 종료 후 닫히며, 이미 조회된 결과도 적용하지 않는다. 네트워크 요청 타임아웃은 10초다.
- 법정동코드가 경량 영문주소 DB의 단일 결과와 일치하면 영문주소도 함께 채운다. 기존 값은 기본적으로 유지한다.

## 매핑·저장

구조 필드에서 국가, 시도, 시군구, 읍면동, 상세를 가져온다. 상세는 level5 우선, 없으면 detail이다.
level2/level3의 일반 시·구는 내부에서 분리하고 기존 시군구 엑셀 컬럼에는 공백으로 연결한다.
실제 안양시 응답처럼 level2가 `안양시 동안구`이고 level3가 빈 경우도 분리한다.
VWorld 경로에서는 Nominatim의 과거 행정구역 강제 변환 규칙을 적용하지 않는다.

법정동코드, 원본 구조, 별도 시구, 보조 상세주소, 조회 좌표는 `_vworld_address` 메타데이터로 임시저장한다.
편집폼·테이블·정렬·임시저장 복원 시 보존하며 좌표나 적용 주소가 수동 변경되면 유효하지 않은 메타데이터는 저장하지 않는다.
빈칸 채우기로 기존 주소와 조회 주소가 혼합되면 `matches_displayed_address=false`로 기록한다.
향후 법정동코드를 영문 검색에 사용할 때 이 상태를 확인해야 한다.
기존 엑셀 컬럼은 유지한다. 엑셀만 다시 불러오거나 텍스트 클립보드로 복사할 경우 내부 메타데이터는 전달되지 않는다.

## 실제 응답 확인

2026-10-27 등록된 키로 공개 좌표 6곳을 조회했다. 키나 요청 URL은 저장하지 않았다.
정규화된 실제 결과: `tests/fixtures/vworld_live_addresses.json`.

| 사례 | 실제 주소/상태 |
| --- | --- |
| 서울 | 서울특별시 중구 태평로1가 31 |
| 안양 | 경기도 안양시 동안구 관양동 1590 |
| 부산 | 부산광역시 동래구 복천동 381 |
| 경주 | 경상북도 경주시 동천동 800 |
| 남해 | 경상남도 남해군 남해읍 서변리 24-1 |
| 해양 | 결과 없음 |

남해 응답의 서변리는 전체 주소 text에 있지만 level4L은 남해읍, level5는 24-1이다.
이번 구현은 승인된 structure 매핑을 따른다. 전체 text에서 리를 추정해 상세주소를 변경하지 않는다.

관련 테스트:
`python -m pytest tests/test_vworld_integration.py tests/test_vworld_services.py tests/test_upload_workflow.py -q`

실제 응답 매핑, 관찰/표본 연동, 기존 주소·영문 보존, 부분 실패, 취소, 오래된 결과 차단,
메타데이터 저장·복원·정렬, 오류 및 보안 저장을 검증한다.
전체 기능 회귀 테스트와 보안 저장 서비스의 검증용 EXE 확인은 [5단계 검증 결과](vworld-validation.md)에 기록했다. Nominatim 코드는 비교·회귀 검증용으로 유지한다.
