# NARIS 미디어 INSERT SQL 생성

SQL 생성 메뉴는 엑셀 데이터를 Oracle INSERT 문으로 변환하고 검수용 엑셀을 만듭니다. DB 접속·SQL 실행·NAS 접속·파일 이동은 수행하지 않습니다.

## 사용 순서

1. 왼쪽 메뉴에서 **SQL 생성**을 엽니다.
2. **엑셀 선택**에서 `.xlsx` 또는 `.xls` 파일을 선택합니다.
3. 시트와 헤더 행을 선택합니다. 첫 시트를 기본 선택하며 숨김 시트는 `(숨김)`으로 표시합니다. 원본·완성본의 컬럼명을 비교해 헤더 행을 자동 제안하며, NARIS 완성본은 보통 2행을 선택합니다. 직접 수정할 수도 있습니다.
4. 파일명·시트명·전체 데이터 행 수·컬럼 수·컬럼명을 확인합니다. 기본 미리보기는 20행입니다.
5. **SQL 작성**에서 관찰이미지·관찰동영상·관찰소리·표본이미지 중 하나를 선택합니다.
6. 매핑 창의 **컬럼 매핑·타입·길이** 탭에서 엑셀 컬럼이나 고정값을 지정합니다. 매핑이 있으면 고정값보다 우선합니다.
   파일명 컬럼에 데이터베이스번호를 선택했다면 **확장자 (선택)**에 `.jpg`, `.mp4`, `.wav` 등을 지정할 수 있습니다. 동영상 파일명과 썸네일 파일명은 각각 다른 확장자를 지정할 수 있으며, 직접 입력도 가능합니다. 비워두면 원래 값을 사용하고 이미 확장자가 있는 파일명은 그대로 유지합니다. 실제 파일명과 일치하도록 선택하세요. 확장자를 포함한 최종 값에 길이·중복 검사를 적용하며 실제 파일은 변경하지 않습니다.
7. **유형 필터·NAS·SEQ·코드** 탭에서 실제 서버 경로와 코드, 채번 규칙을 확인합니다.
8. 실제 DB 스키마 확인을 체크한 후 **검증 및 SQL 생성**을 실행합니다.
9. 결과에서 `SUCCESS`, `ERROR`, `SKIP`을 확인하고 행을 선택해 SQL이나 오류 내용을 봅니다.
10. **TXT + 검수 XLSX 저장**으로 결과를 저장합니다. TXT 대신 `.sql` 확장자도 사용할 수 있습니다.

시트·헤더 행·입력 파일을 바꾸면 이전 생성 결과가 초기화됩니다. 화면에는 최대 500개 결과를 표시하며 저장 파일에는 전체 결과를 기록합니다.

## 폴더에서 실제 파일명 가져오기

확장자를 직접 붙이는 대신 실제 파일명으로 SQL을 만들 수도 있습니다.

1. 매핑 창에서 **파일명 매칭 폴더 → 폴더 선택**을 누릅니다.
2. 필요한 파일명 컬럼의 **파일명 가져오기**를 **폴더 ↔ DB 번호**로 바꿉니다.
3. 설정 탭에서 **DB 번호 컬럼**을 확인합니다. 엑셀의 DB 번호와 확장자를 제외한 파일명이 정확히 같은 파일을 찾습니다. 대소문자 차이는 허용하며 결과에는 실제 파일명의 대소문자를 유지합니다.
4. 동영상 파일명에는 동영상 확장자의 파일을, 대표 썸네일에는 이미지 파일을 연결합니다. 이미지는 이미지 파일, 소리는 소리 파일로 분류합니다.
5. 기본적으로 종고유ID 등 하위 폴더도 검색하고 미리보기용 `썸네일` 하위 폴더는 제외합니다. 두 옵션은 변경할 수 있습니다.
6. 후보가 여러 개면 임의 선택하지 않고 `ERROR`로 표시합니다. 폴더를 더 좁히거나 **확장자 (선택)**으로 `.jpg`, `.mp4` 등 특정 확장자를 지정하세요. 폴더 모드에서 확장자는 파일명을 변경하는 옵션이 아니라 검색 필터입니다.

예: DB 번호 `ABC-001`에 대해 실제 `ABC-001.MP4`와 `ABC-001.jpg`가 있다면 동영상 컬럼에는 `ABC-001.MP4`, 썸네일 컬럼에는 `ABC-001.jpg`를 사용합니다. 없는 파일은 만들어내지 않으며 일치하지 않는 파일명을 추측하지 않습니다. 원본파일명 컬럼도 사용자가 선택한 경우에만 폴더 모드를 적용합니다.

이 기능은 사용자가 지정한 폴더의 파일명만 조회합니다. 파일을 이동·복사·수정하지 않으며 DB에 넣을 NAS 경로는 별도 설정값을 사용합니다.

## 대상 테이블과 연결 키

| 유형 | 테이블 | 연결 키 | 기본 SEQ |
|---|---|---|---|
| 관찰이미지 | TB_SBD_OBSRV_IMAGE_INFO | 관찰정보순번 → OBSRV_INFO_SEQ | 1 |
| 표본이미지 | TB_SBD_SPECS_IMAGE_INFO | 종고유ID → SPECS_ESSNT_ID | 1 |
| 관찰동영상 | TB_SBD_LVBNG_MVPCT_INFO | 종고유ID → SPECS_ESSNT_ID | 실행 시 연결 키별 MAX + 1 |
| 관찰소리 | TB_SBD_LVBNG_SOUND_INFO | 종고유ID → SPECS_ESSNT_ID | 실행 시 연결 키별 MAX + 1 |

이미지 구분 코드는 사용자 확인에 따라 `'03'`을 기본으로 설정했습니다. 이미지 고정 순번이 같은 연결 키에서 중복되면 충돌하는 행 전체를 `ERROR`로 표시합니다. 관찰정보순번이 없다고 종고유ID나 NO.를 대신 사용하지 않습니다. 표본 개별 ID와의 관계는 실제 DB 구조에서 별도로 확인해야 합니다.

## 미확정 값 처리

- DB 컬럼 최대 길이, 길이 단위(BYTE/CHAR), 필수값과 실제 키 구조는 실제 DDL을 확인해 설정합니다. 알 수 없는 문자열 길이는 `미확정`으로 표시하고 해당 값의 SQL 생성을 막습니다.
- `NUMBER`의 구체적인 precision/scale, 실제 FK 존재 여부와 기존 DB의 중복 여부는 실제 DB 스키마·데이터에서 별도 확인해야 합니다.
- 동영상 대표 썸네일은 파일명을 매핑하거나 직접 입력해야 합니다. 동영상 파일명에서 임의 생성하지 않습니다. 최대 길이 100과 필수 여부를 검증합니다.
- 관찰동영상의 `LVBNG_MVPCT_USE_YN`과 관찰소리의 `LVBNG_SOUND_USE_YN`은 확인된 값 `Y`로 고정 생성합니다.
- 미디어코드 `OB` 등은 이미지나 동영상으로 임의 해석하지 않습니다. 코드 컬럼을 사용하면 대상·제외 코드를 설정해야 합니다. 미디어타입만 사용하려면 코드 컬럼을 매핑 해제합니다.
- NARIS 완성본처럼 유형 구분 컬럼이 없는 파일은 ‘SQL 작성’에서 고른 유형으로 전체 행을 처리하는 옵션을 기본 적용하고 화면에 안내합니다. 유형 컬럼이 있으면 행별 필터를 유지하며, 코드가 미확정이거나 값이 비어 있다고 이 옵션으로 자동 우회하지 않습니다.
- 표본 완성본의 `이전데이터베이스번호`는 일반 `데이터베이스번호` 컬럼이 없을 때 DB 번호 매핑 후보로 사용합니다.
- 이미지 NAS 경로는 미확정 상태이므로 직접 입력해야 합니다.

기본 매핑은 `config/sql_media_profiles.py`, 사용자 매핑은 `SETTINGS_DIR/sql_media_mappings.json`에서 유형별로 관리합니다. 숫자·문자열 필드만 다루며 임의의 SQL 표현식을 입력하는 기능은 제공하지 않습니다.

## NAS 경로

- 동영상: `/NAS/naris/movie/naris/specs/{SPECS_ESSNT_ID}/`
- 소리: `/NAS/naris/sound/naris/specs/{SPECS_ESSNT_ID}/`
- 이미지는 실제 NAS 경로를 직접 지정합니다. 연결 키에 따라 `{OBSRV_INFO_SEQ}` 또는 `{SPECS_ESSNT_ID}`를 사용할 수 있습니다.
- 폴더 경로와 파일명은 별도 DB 컬럼으로 저장하며, PC의 `C:\...` 경로를 NAS 경로로 사용하지 않습니다.
- NAS 폴더나 파일이 실제로 존재하는지는 조회하지 않습니다.

## SQL 변환과 실행

- 빈 값은 `NULL`, 문자열 내 작은따옴표는 두 번으로 처리합니다. 줄바꿈은 `CHR(10)`/`CHR(13)` 표현식으로 보존합니다.
- 재생시간은 `HH:MM`으로 변환하며 초는 버립니다. 문자열과 엑셀 시간 셀을 지원합니다.
- 동영상 국문 내용 뒤에는 `<br> : 데이터베이스번호`를 추가합니다.
- 동영상 제목·설명이 비어 있으면 국문은 국명, 영문은 학명으로 보완합니다. 이미 작성한 항목은 유지하며, 대체에 사용할 국명·학명 컬럼도 설정 화면에서 매핑할 수 있습니다. 이때도 DB 컬럼 길이 검사를 적용합니다.
- 동영상·소리의 최초등록자는 `'narisorg'`, 최초등록시점은 `SYSDATE`입니다.
- 재계산되지 않아 값이 없는 수식은 매핑된 필드에서 오류 처리합니다. 엑셀에서 재계산·저장 후 다시 불러오세요.
- 실행용 파일은 SQL*Plus/SQL Developer의 **스크립트 실행**을 기준으로 `SET DEFINE OFF`, `SET SQLBLANKLINES ON`, `SET AUTOCOMMIT OFF`를 포함합니다. `&`가 치환 변수로 취급되지 않도록 하는 설정은 [Oracle 공식 설명](https://docs.oracle.com/en/database/oracle/oracle-database/21/sqpug/using-substitution-variables-sqlplus.html)을 참고하세요.
- 기본적으로 `LOCK TABLE ... IN EXCLUSIVE MODE`를 포함하며, 하나의 DB 세션에서 순차 실행합니다. 테이블 잠금 옵션을 끄면 동시 MAX+1 충돌 방지는 사용자가 별도로 관리해야 합니다.
- 자동 COMMIT은 포함하지 않습니다. 실행 권한·잠금 영향·제약조건과 실행 결과는 DB 담당자가 검토해야 합니다.

## 결과 저장과 원본 보존

- TXT/SQL에는 `SUCCESS` 행만 입력 순서대로 기록합니다.
- 검수용 XLSX에는 선택 시트 마지막에 `INSERT_SQL`, `SQL_STATUS`, `SQL_ERROR`를 추가합니다. 오류에는 원본 엑셀 행 번호를 기록합니다.
- 원본 파일을 덮어쓰지 않습니다. 원본 시트·데이터는 유지하고 선택하지 않은 시트는 수정하지 않습니다.
- `.xlsx`는 원본 수식·서식을 유지합니다. `.xls`는 XLSX로 변환하며 셀 값·시트·표시 형식·병합을 유지하지만 수식은 계산 결과가 되고 일부 서식은 변환 과정에서 달라질 수 있습니다.
- SQL 셀의 32767자 제한을 초과하면 오류 처리합니다.
- 두 결과를 먼저 임시 생성한 뒤 저장하며, 저장 중 실패하면 이미 교체한 결과를 복원합니다.
