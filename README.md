# BioFlow

생물표본/관찰정보 데이터 입력, 종정보 마스터 관리, 신규·업데이트 종 정리를 위한 PySide6 기반 데스크톱 도구입니다.

## 주요 기능

### 종정보 마스터 (`종정보 마스터` 탭)
- 종정보 마스터 엑셀 업로드, 로컬 저장(버전 이력 관리)
- 업데이트 파일 여러 개를 선택해 신규/업데이트 후보 자동 분류
- 분류 결과를 엑셀로 저장

### 신규 데이터 (`신규 데이터` 탭)
사업/기관 참조데이터를 공유하는 4개 서브탭으로 구성됩니다.

- **관찰 정보작성**: 관찰정보 행 단위 입력. 국명 입력 시 학명/종고유ID 자동 매칭, 주소(시도/시군구/읍면동/상세) 국→영 자동 매칭 및 자동완성, 위경도 기반 역지오코딩(OpenStreetMap Nominatim), 이미지/동영상/사운드 등록 시 EXIF/메타데이터에서 위치·재생시간·촬영일 자동 추출. **미디어 폴더 일괄 불러오기**로 폴더 안 이미지/동영상/사운드 파일을 한 번에 행으로 추가(진행률 표시, 취소 가능). 동영상 캡처 이미지는 "동영상 캡처 이미지 생성" 버튼으로 일괄 생성되며, 원본 동영상과 섞이지 않도록 같은 폴더의 `썸네일` 하위 폴더에 저장됩니다. 표에서 셀을 직접 편집(더블클릭/타이핑/채우기 핸들 드래그 복사)해도 국명 조회·날짜 형식 변환이 동일하게 적용되고, 붙여넣기로 국명을 채운 경우도 현재 폼에 로드된 행이면 동일하게 적용됩니다.
- **표본정보 작성**: 표본 데이터 입력. 데이터베이스번호는 `기관코드-SP-분류코드-연도순번No` 규칙으로 자동 생성. 국명 조회 시 학명/종고유ID/속명/종명 자동 입력(과명은 마스터에 없어 직접 입력), 자동입력 값을 수동으로 고치면 노란색으로 표시되어 추후 검토 시 구분 가능. 이미지 등록·위치/날짜 자동 추출 지원, **이미지 폴더 일괄 불러오기**로 폴더 안 이미지 파일을 한 번에 행으로 추가 가능. 분류코드는 기본 목록(IN/PL/BI/PI/MM/SP/MR/AR/AM/SW/AG) 외에 직접 입력도 가능합니다.
- **사업 관리 / 기관 관리**: 두 서브탭에서 공유하는 사업·기관 참조 목록 관리.

공통 기능: 임시저장(자동저장), 엑셀 불러오기/저장(원본 + 완성본 재구성 파일), 미디어 파일은 저장 시 원본 폴더와 다른 위치에만 복사되며 원본 경로/파일명(`원본경로`/`원본파일명`, 확장자 제외)과 저장된 경로/파일명(`파일경로`/`파일명`)을 모두 기록합니다. 표에서 셀(또는 범위)을 선택해 Ctrl+C/Ctrl+V로 복사·붙여넣기할 수 있고, 가로(행)·세로(열)·사각형 범위 모두 지원합니다. "이 행 위치 확인" 버튼으로 입력한 위도/경도 위치를 기본 브라우저의 OpenStreetMap에서 열어 오입력 여부를 확인할 수 있고, "전체 위치 지도 확인" 버튼은 위도/경도가 있는 모든 행을 데이터베이스번호·좌표·주소가 담긴 핀으로 한 지도에 모아서 보여줍니다. "위치 전체 주소 조회" 버튼으로 주소가 비어있는 행들의 주소를 좌표 기반으로 일괄 조회할 수 있습니다(조회 서비스 제한으로 행이 많으면 시간이 걸립니다). 위도/경도가 범위를 벗어나거나 서로 뒤바뀐 것처럼 보이거나 국내 범위를 벗어나면 표에서 해당 셀이 빨간색으로 표시(마우스를 올리면 사유 표시)되고, 엑셀로 저장하기 직전에도 문제가 있는 행 목록을 팝업으로 보여주고 계속할지 확인합니다. 국가국문명/국가영문명은 기본값(대한민국/Republic of Korea)이 채워지며 필요 시 수정 가능합니다. 동정년월일/관찰일/채집년월일은 `260508`, `20260508`처럼 숫자만 입력해도 `2026-05-08` 형식으로 자동 변환됩니다.

### 신규/업데이트 종 정리 (`신규/업데이트 종 정리` 탭)
- 관찰정보에서 미매칭(종고유ID 없는) 종 자동 수집
- 이전 국명/이전 학명 엑셀 불러오기: 국명만 있는 파일이라도 종정보 마스터와 **정확히 일치**할 때만 기존ID값·이전 학명·분류체계명(clssc_sstem_kor/latin)을 자동 매칭 (유사매칭 없음, 다르면 빈칸)
- 신규/업데이트 여부, 국문·영문 분류체계 정보를 정리해 엑셀로 저장

### 비교 결과 / SQL 생성 / GBIF 데이터
현재 준비 중인 탭입니다.

## 실행 (소스에서)

```powershell
pip install -r requirements.txt
python app.py
```

Python 3.10 기준으로 개발되었습니다.

## 배포용 빌드 (exe)

[PyInstaller](https://pyinstaller.org/)로 패키징합니다.

```powershell
pip install pyinstaller
pyinstaller BioFlow.spec
```

빌드 전에 `VERSION` 파일의 버전 문자열을 올려주세요. 빌드 결과물은 `dist/BioFlow-<VERSION>/`(exe + `_internal` 폴더)에 버전별로 따로 생성되며, 이전 버전 폴더는 덮어쓰지 않습니다. 이 폴더 전체를 그대로 압축해서 배포하면 됩니다. (코드에서 쓰지 않는 scipy/pyarrow는 `BioFlow.spec`의 `excludes`에서 제외해 빌드 용량을 줄여둔 상태입니다.)

### 사용자 데이터 위치

- 개발 중(`python app.py`로 실행): 프로젝트 루트의 `data/`, `cache/`, `logs/` 사용
- 빌드된 exe로 실행: 항상 **내 문서\BioFlow**(`data/`, `cache/`, `logs/`) 사용 — Program Files 등 쓰기 금지 위치에 설치해도 문제없이 저장되며, 앱을 재설치/업데이트해도 유지됩니다.
- 최초 실행 시 exe에 번들된 참조 데이터(사업/기관 목록, 종정보 마스터 등)가 내 문서\BioFlow로 자동 복사됩니다. 작성 중이던 임시저장 데이터는 시드에서 제외됩니다.

## 프로젝트 구조

```
app.py                 앱 진입점
config/paths.py         데이터/캐시/로그 경로 (개발 모드 vs 빌드된 exe 모드 자동 분기)
ui/main_window.py       메인 창, 탭 구성
ui/tabs/                각 탭 UI (upload_tab.py가 신규 데이터 탭 전체를 담당)
services/                종정보 마스터, 주소 마스터 등 서비스 레이어
data/                   참조데이터·종정보 마스터 원본(개발 모드에서 사용)
BioFlow.spec             PyInstaller 빌드 설정
```
