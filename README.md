# BioFlow

생물표본/관찰정보 데이터 입력, 종정보 마스터 관리, 신규·업데이트 종 정리를 위한 PySide6 기반 데스크톱 도구입니다.

### 1. 종정보 마스터 불러오기와 종 검색

![종정보 마스터 불러오기와 종 검색](docs/presentation/BioFlow_01_master_search.gif)

1. 왼쪽 메뉴에서 **종정보 마스터**를 누릅니다.
2. 마스터를 불러오는 동안 기다립니다. 완료되면 전체 건수와 함께 상위 200건이 표시됩니다.
3. **종 검색** 탭에서 학명·국명·분류군 중 하나를 입력해 찾습니다. (예: 국명 `큰고니`, 분류군 `포유`)

### 2. 사진 폴더 불러오기와 국명 자동 조회

![사진 폴더 불러오기와 국명 자동 조회](docs/presentation/BioFlow_02_media_folder_lookup.gif)

1. **신규 데이터 › 관찰 정보작성** 탭으로 이동합니다.
2. **미디어 폴더 일괄 불러오기**로 폴더를 선택하면 폴더 안 사진이 한 번에 행으로 추가됩니다.
3. 행을 누르면 위쪽 입력 폼에 사진 미리보기와 경로가 표시됩니다.
4. 표의 **국명** 칸에 국명을 입력하면 학명·종고유ID·DB 번호가 자동으로 채워집니다. (예: `소나무`)
5. 입력 폼에서 분류코드·사업명·기관명도 확인합니다.

### 3. 사진 위치정보 자동 입력과 주소 조회

![사진 위치정보 자동 입력과 주소 조회](docs/presentation/BioFlow_03_photo_gps_address.gif)

1. 위치정보가 있는 사진을 불러오면 위도·경도가 자동으로 입력됩니다.
2. **위치 전체 주소 조회**를 누르고 VWorld 결과 미리보기에서 **Apply**를 선택하면 비어 있는 국문주소가 채워집니다. API 키는 **설정 → VWorld API 설정**에서 등록합니다. 법정동코드가 영문 기준 DB와 일치하면 영문 빈칸도 함께 채웁니다. 덮어쓰기를 선택하지 않으면 기존 값은 유지됩니다.
3. **종ID·사업·미디어 일괄 적용**으로 분류코드·사업별 순번 등을 한 번에 입력합니다.
4. 결과 메시지에 `종 매칭 0행`이 나오면 국명이 비어 있는 것이므로, 국명을 입력한 뒤 다시 확인합니다.

### 4. 동영상 등록과 미리보기 생성

![동영상 등록과 미리보기 생성](docs/presentation/BioFlow_04_video_media.gif)

1. 미디어타입을 **동영상**으로 두고 동영상을 불러오면 재생시간이 자동으로 입력됩니다.
2. **동영상 미리보기 생성**을 누르면 현재 동영상 폴더의 `썸네일` 하위 폴더에 미리보기 JPG가 만들어지고 화면에 표시됩니다.
3. 표에서 동영상 제목·상세설명을 입력합니다.
4. 국명을 입력해 학명·종고유ID를 채우고, 사업별 순번과 분류코드를 입력하면 행마다 DB 번호가 만들어집니다.

### 5. 엑셀 불러오기, 일괄 적용, 엑셀 저장

![엑셀 불러오기, 일괄 적용, 엑셀 저장](docs/presentation/BioFlow_05_excel_bulk_save.gif)

1. **작성 내용 비우기**로 표를 비우고 새로 시작합니다.
2. **엑셀 불러오기** → 시트 선택 → 컬럼 매핑을 확인합니다.
3. 아래 상태 메시지에서 불러온 건수를 확인합니다. (영상 예: 900건)
4. **종ID·사업·미디어 일괄 적용**을 실행하고, 완료 메시지의 전체 행 수와 종 매칭 행 수를 확인합니다.
5. **데이터 검사**로 확인한 뒤 **엑셀로 저장**을 누릅니다.
6. 저장이 끝나면 작성 내용이 초기화되고 새 작성이 NO. 1부터 시작됩니다.

> 녹화에는 메인 창만 담겨 있어, 시트 선택·일괄 적용 설정 같은 별도 창은 GIF에 나오지 않습니다.

### 6. 위치 전체 주소 조회와 좌표 오류 수정

![위치 전체 주소 조회와 좌표 오류 수정](docs/presentation/BioFlow_06_address_coord_fix.gif)

1. 엑셀을 불러온 뒤 좌표가 **빨간색**인 셀을 찾습니다. (영상 예: 13행)
2. **위치 전체 주소 조회**로 좌표가 정상인 행의 주소를 먼저 채웁니다. 행이 많으면 시간이 걸립니다.
3. 잘못 입력된 좌표를 고칩니다. (예: 경도 `12923475` → `129.23475`)
4. 다시 **위치 전체 주소 조회**를 눌러 고친 행의 주소도 채우고, 결과 메시지에서 성공 행 수를 확인합니다.

### 7. 마스터에 없는 종 정리

![마스터에 없는 종 정리](docs/presentation/BioFlow_07_new_update_species.gif)

1. 관찰 정보작성에서 국명을 입력했을 때 `마스터 매칭 없음`이 나오는 종이 정리 대상입니다. (예: `찔레`)
2. **신규/업데이트 종 정리** 메뉴에서 **관찰정보에서 미매칭 종 가져오기**를 누릅니다.
3. 구분을 **업데이트 필요**로 바꾸고 이전 국명을 입력하면, 종정보 마스터와 정확히 일치할 때 기존ID가 자동으로 매칭됩니다. (예: `찔레꽃`)
4. 분류체계 정보를 확인한 뒤 **엑셀로 저장**을 누릅니다.

> 더 자세한 설명은 사용자 매뉴얼(슬라이드)을 참고하세요.

## 주요 기능

### 종정보 마스터 (`종정보 마스터` 탭)

- 종정보 마스터 엑셀 업로드 후 SQLite로 변환·교체, 로컬 저장(버전 이력 관리)
- 종정보 미리보기 영역을 크게 표시하며 최대 200행 확인
- 학명·국명·분류군으로 종 검색 및 검색 결과 엑셀 저장
- 신규·업데이트 종 작업은 `신규/업데이트 종 정리` 메뉴에서 진행

### 신규 데이터 (`신규 데이터` 탭)

사업/기관 참조데이터를 공유하는 4개 서브탭으로 구성됩니다.

- **관찰 정보작성**: 관찰정보 행 단위 입력. 국명 입력 시 학명/종고유ID 자동 매칭, 주소(시도/시군구/읍면동/리) 법정동코드 기반 영문 자동 매핑, 위경도 기반 국문주소 조회(VWorld API 2.0, 사용자별 키 등록), 이미지/동영상/사운드 등록 시 EXIF/메타데이터에서 위치·재생시간·촬영일 자동 추출. **미디어 폴더 일괄 불러오기**로 폴더 안 이미지/동영상/사운드 파일을 한 번에 행으로 추가(진행률 표시, 취소 가능). 동영상은 지정한 저장 위치 아래 `종고유ID/DB번호.확장자`로 먼저 복사한 뒤, 저장된 동영상에서 같은 폴더의 `DB번호.jpg` 캡처를 생성합니다. 엑셀 저장 시에는 종고유ID가 필요합니다. "동영상 미리보기 생성" 버튼은 파일 이동이나 저장 폴더 선택 없이 현재 동영상 폴더의 `썸네일` 하위 폴더에 미리보기용 JPG만 생성하며, 종고유ID가 없어도 사용할 수 있습니다. 표에서 셀을 직접 편집(더블클릭/타이핑/채우기 핸들 드래그 복사)해도 국명 조회·날짜 형식 변환이 동일하게 적용되고, 붙여넣기로 국명을 채운 경우도 현재 폼에 로드된 행이면 동일하게 적용됩니다.
- **표본정보 작성**: 표본 데이터 입력. 데이터베이스번호는 `기관코드-분류코드-연도순번No` 규칙으로 자동 생성(예: `NSMK-PL-260700005`). 국명 조회 시 학명/종고유ID/속명/종명 자동 입력(과명은 마스터에 없어 직접 입력), 자동입력 값을 수동으로 고치면 노란색으로 표시되어 추후 검토 시 구분 가능. 이미지 등록·위치/날짜 자동 추출 지원, **이미지 폴더 일괄 불러오기**로 폴더 안 이미지 파일을 한 번에 행으로 추가 가능. 분류코드는 기본 목록(IN/PL/BI/PI/MM/SP/MR/AR/AM/SW/AG) 외에 직접 입력도 가능합니다.
- **사업 관리 / 기관 관리**: 두 서브탭에서 공유하는 사업·기관 참조 목록 관리.

공통 기능: 임시저장(자동저장), 엑셀 불러오기/저장(원본 + 완성본 재구성 파일), 미디어 파일은 저장 시 원본 폴더와 다른 위치에만 복사되며 원본 경로/파일명(`원본경로`/`원본파일명`, 확장자 제외)과 저장된 경로/파일명(`파일경로`/`파일명`)을 모두 기록합니다. 표에서 셀(또는 범위)을 선택해 Ctrl+C/Ctrl+V로 복사·붙여넣기할 수 있고, 가로(행)·세로(열)·사각형 범위 모두 지원합니다. "이 행 위치 확인" 버튼으로 입력한 위도/경도 위치를 기본 브라우저의 OpenStreetMap에서 열어 오입력 여부를 확인할 수 있고, "전체 위치 지도 확인" 버튼은 위도/경도가 있는 모든 행을 데이터베이스번호·좌표·주소가 담긴 핀으로 한 지도에 모아서 보여줍니다. "위치 전체 주소 조회" 버튼으로 좌표가 유효한 행의 주소를 일괄 조회하고 미리보기에서 적용할 수 있습니다. 기본값은 빈칸만 채우기이며 기존 국문주소 덮어쓰기를 선택할 수 있습니다(조회 서비스 제한으로 행이 많으면 시간이 걸립니다). 위도/경도가 범위를 벗어나거나 서로 뒤바뀐 것처럼 보이거나 국내 범위를 벗어나면 표에서 해당 셀이 빨간색으로 표시(마우스를 올리면 사유 표시)되고, 엑셀로 저장하기 직전에도 문제가 있는 행 목록을 팝업으로 보여주고 계속할지 확인합니다. 국가국문명/국가영문명은 기본값(대한민국/Republic of Korea)이 채워지며 필요 시 수정 가능합니다. 동정년월일/관찰일/채집년월일은 `260508`, `20260508`처럼 숫자만 입력해도 `2026-05-08` 형식으로 자동 변환됩니다.

### 엑셀 저장 결과 (관찰·표본 공통)

‘엑셀로 저장’을 실행하면 선택한 파일명 기준으로 같은 폴더에 3개 파일을 생성합니다.

- `파일명.xlsx`: 작성 데이터 원본
- `파일명_완성본.xlsx`: 기존 완성본 양식
- `파일명_GBIF.xlsx`: 제공된 GBIF 양식의 17개 컬럼과 서식을 적용한 파일

GBIF 파일은 DB 번호를 `occurrenceID`와 `catalogNumber`에, 분류코드를 `collectionCode`에 연결합니다. 관찰정보는 `HumanObservation`과 관찰일을, 표본정보는 `PreservedSpecimen`과 채집년월일을 사용합니다. 동정자와 주소는 영문 필드에서 가져오며, 입력하지 않은 정보는 빈칸으로 남깁니다. 국가명은 확인 가능한 경우에만 2자리 국가코드로 변환하고, 알 수 없는 국가명은 빈칸으로 남깁니다. 제공 양식의 예시 데이터는 결과에 포함하지 않습니다.

3개 파일 저장이 모두 성공한 뒤 작성 내용을 초기화합니다. 중간에 실패하면 작성 내용을 유지하며, 앞서 생성된 파일이 일부 남아 있을 수 있습니다. GBIF 파일 생성은 로컬 엑셀 변환 기능이며 온라인 업로드는 수행하지 않습니다.

엑셀 저장 시 미디어가 있는 경우에는 매번 미디어 저장 폴더 선택 창을 표시합니다. 이전 위치는 선택 창의 시작 위치로만 사용합니다. 폴더 선택을 취소하면 엑셀 저장을 중단하고 작성 내용을 유지하며, 미디어가 없는 데이터는 폴더를 묻지 않고 엑셀만 저장합니다. 관찰·표본 이미지는 선택한 폴더에 모아 저장하고, 동영상과 캡처만 `종고유ID` 하위 폴더에 저장합니다.

### 신규/업데이트 종 정리 (`신규/업데이트 종 정리` 탭)

- 관찰정보에서 미매칭(종고유ID 없는) 종 자동 수집
- 이전 국명/이전 학명 엑셀 불러오기: 국명만 있는 파일이라도 종정보 마스터와 **정확히 일치**할 때만 기존ID값·이전 학명·분류체계명(clssc_sstem_kor/latin)을 자동 매칭 (유사매칭 없음, 다르면 빈칸)
- 신규/업데이트 여부, 국문·영문 분류체계 정보를 정리해 엑셀로 저장

### SQL 생성

- `.xlsx`·`.xls` 파일의 시트와 헤더 행을 선택하고 기본 20행 미리보기 확인
- 관찰이미지·관찰동영상·관찰소리·표본이미지의 Oracle INSERT SQL 생성
- DB 컬럼 매핑, NAS 경로, 유형 필터, SEQ 규칙, 실제 DB 타입·문자열 길이 설정
- 이미지는 기본 `IMAGE_SEQ = 1`, `IMAGE_TPCD = '03'` 적용. 같은 연결 ID의 순번 중복은 오류 처리
- 실행용 UTF-8 TXT/SQL과 원본 시트·데이터에 검증 결과를 추가한 XLSX를 함께 저장
- 실제 DB 접속·SQL 실행·NAS 파일 이동은 하지 않음

확정되지 않은 DB 스키마·이미지 NAS 경로는 설정 화면에서 확인해야 하며, 임의 값으로 SQL을 생성하지 않습니다. 관찰동영상·관찰소리 사용 여부는 확인된 값 `Y`로 생성합니다. 자세한 사용 방법은 [SQL 생성 안내](docs/NARIS_SQL.md)를 참고하세요.

### 비교 결과 / GBIF 데이터

현재 준비 중인 탭입니다.

## 실행 (소스에서)

```powershell
pip install -r requirements.txt
python app.py
```

Python 3.10 기준으로 개발되었습니다.

## 배포용 빌드 (exe)

[PyInstaller](https://pyinstaller.org/)로 패키징합니다.

```powershell
pip install pyinstaller
pyinstaller BioFlow.spec
```

빌드 전에 `VERSION` 파일의 버전 문자열을 올려주세요. 빌드 결과물은 `dist/BioFlow-<VERSION>/`(exe + `_internal` 폴더)에 버전별로 따로 생성되며, 이전 버전 폴더는 덮어쓰지 않습니다. 이 폴더 전체를 그대로 압축해서 배포하면 됩니다. (코드에서 쓰지 않는 scipy/pyarrow는 `BioFlow.spec`의 `excludes`에서 제외해 빌드 용량을 줄여둔 상태입니다.)

### 사용자 데이터 위치

- 개발 중(`python app.py`로 실행): 프로젝트 루트의 `data/`, `cache/`, `logs/` 사용
- 빌드된 exe로 실행: 항상 **내 문서\BioFlow**(`data/`, `cache/`, `logs/`) 사용 — Program Files 등 쓰기 금지 위치에 설치해도 문제없이 저장되며, 앱을 재설치/업데이트해도 유지됩니다.
- 최초 실행 시 exe에 번들된 참조 데이터(사업/기관 목록, 종정보 마스터 등)가 내 문서\BioFlow로 자동 복사됩니다. 작성 중이던 임시저장 데이터는 시드에서 제외됩니다.
